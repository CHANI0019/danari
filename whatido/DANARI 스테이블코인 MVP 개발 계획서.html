DANARI 스테이블코인

MVP 인터랙티브 개발 계획서

프로젝트 목표

"소규모별로 통제된 환경(회사가 취득한 자산)에서, 관리자가 원화 입금을 기반으로 DUSD를 발행하고, 사용자가 이 DUSD를 QR코드로 결제하는 핵심 사이클을 기술적으로 증명합니다."

성공 측정 기준

✅ 기능: QR 결제 최소 1회 성공
💾 데이터: 모든 거래의 정확한 기록
👍 피드백: 긍정적인 내부 테스트 경험

개발 로드맵 타임라인

목표: MVP 기능 범위 확정 및 시스템 청사진 설계

✔️ MVP 기능 명세

  • 관리자: 발행량 확인, DUSD 발행, 거래 내역 조회
  • 사용자: 회원가입, 잔액 확인, QR 결제, 거래 내역 조회

📝 UI/UX 와이어프레임

Figma, Balsamiq 등을 활용하여 사용자 앱과 관리자 대시보드의 핵심 화면 흐름(Flow)을 스케치합니다.

🏗️ 기술 아키텍처 & DB 설계

시스템 구조도, API 명세, 데이터베이스 스키마를 정의하여 기술적 기반을 마련합니다.

🛠️ 개발 환경 구축

GitHub 저장소 생성 및 Jira, Trello 등 프로젝트 관리 도구를 통해 개발 일정을 체계적으로 관리합니다.

목표: 시스템의 핵심 엔진인 서버 로직과 블록체인 계약 개발

관리자의 발행 요청이 블록체인에 기록되기까지의 핵심 로직을 구현합니다. 아래 다이어그램의 각 단계에 마우스를 올려보세요.

1. 관리자가 대시보드에서 '토큰 발행' 요청
⬇️
2. 백엔드 서버가 API 호출을 수신하고 유효성 검증
⬇️
3. 서버가 `ethers.js`를 통해 스마트 컨트랙트의 `mint` 함수 실행
⬇️
4. 테스트넷에서 트랜잭션 처리 후, 결과(Tx Hash)를 서버에 반환
⬇️
5. 서버가 해당 트랜잭션 정보를 내부 DB에 저장

목표: 사용자와 관리자가 상호작용할 화면 개발

🖥️ 관리자 대시보드 (React)

핵심 지표(총 발행량, 담보 가치 등)를 시각화하고, 'DUSD 발행' 기능을 구현하여 관리자가 시스템을 통제할 수 있도록 합니다.

📱 사용자 앱 (Web App)

사용자가 잔액 확인, QR코드 스캔을 통한 결제, 거래 내역 조회를 할 수 있는 웹 기반 애플리케이션을 개발합니다. MVP 단계에서는 빠른 개발을 위해 웹앱을 우선합니다.
