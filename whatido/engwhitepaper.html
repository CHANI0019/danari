DANARI Stablecoin Whitepaper

Asset-Backed Digital Currency System
Version: 1.0 Last Updated: July 2025

1. Project Overview

DANARI is a stablecoin project backed by real-world assets. The project aims to establish a tangible payment system usable within a hotel by issuing a digital currency (DUSD) collateralized by a hotel located in Incheon, valued at 5 billion KRW.

2. Problem Definition

  • Growing demand for cashless internal economic systems
  • Lack of trust in unstable coins not tied to real-world assets
  • Absence of a unified payment method across various hotel facilities (restaurants, billiard halls, spas, etc.)

3. DANARI Solution

3.1 Real Asset-Backed

DANARI issues a stablecoin (1 DUSD = 1 KRW) collateralized by the Incheon hotel (valued at 5 billion KRW). Token issuance is strictly limited to the hotel's real asset value.

3.2 QR Payment System

All transactions are processed via QR code through the DANARI mobile app. Users and merchants (hotel facilities) can send and receive payments in real-time via the app or web.

3.3 On-Chain Transparency

DANARI is issued as an ERC-20-based smart contract, ensuring all minting, burning, and transfers are transparently recorded on the blockchain.

4. Technical Architecture

4.1 Smart Contract

  • ERC-20 based DanariStableToken contract
  • Decimals: 2
  • No total supply limit (manually controlled based on collateral)
  • Issuer privilege: MINTER_ROLE based

4.2 Backend System

  • Admin API server (FastAPI based)
  • Functions: mint, burn, log queries, internal auditing

4.3 User Application

  • Mobile app (Flutter based with MetaMask integration)
  • QR payment scan/generation functionality

4.4 Admin Dashboard

  • Web dashboard (React based)
  • Functions: supply monitoring, merchant balances, transaction log visualization

6. Use Case Example

  • Hotel guest deposits 10,000 KRW into DANARI → Receives 10,000 DUSD
  • Pays 6,500 DUSD at restaurant via QR scan
  • Remaining 3,500 DUSD can be freely used at other facilities (spa, convenience store, etc.)

7. Collateral & Auditing

  • DANARI tokens are issued based on the real hotel collateral
  • Collateral valuation is periodically reviewed by accounting firms
  • All minting/burning is controlled via admin API with publicly verifiable smart contract

8. Roadmap

Quarter Goal

9. Conclusion

DANARI is a trusted stablecoin backed by real-world assets, starting within a hotel environment and gradually expanding to external services. It offers a transparent, secure blockchain payment alternative for users seeking asset-backed stability.
